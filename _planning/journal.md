# Logbuch zum Kooperationsprojekt SODA-DNS: Minimaler Viewer-Editor

## 6.5.2026 Zoom MZ - MM

Vereinbart:

MM extrahiert eine MVP-Version es bestehenden DNS-Viewer-Editor für die Verwendung mit den gringsten denkbaren infrastrukturellen Voraussetzungen:

- Online-Viewer-Editor als "Demo-Version" auf GitHub Pages
- Daten in JSON mit Upload-Download in Online-Viewer-Editor
- Medien über statisches Hosting (BaseURL + Kennung)
- OCR-Daten als JSON-Datenpaket in den Nutzdaten
- Default Feld-Konfiguration über Namen 
- GUI für explizite Feld-Konfiguration, Persistenz über Upload/Download JSON

MZ wird dann geeignete Anwendungsprojekte identifzieren und für diese das Datenmapping übernehmen.

Zielsetzung: 

Frage klären, ob dieser minimalistische Ansatz in der Praxis einen erkennbaren Nutzwert hat.
