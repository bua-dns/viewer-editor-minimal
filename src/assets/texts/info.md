# Getting Started

1. Tab wählen: Nutze `Editieren` für die Bearbeitung und `Info` für diese Kurzanleitung.
2. Datei laden: Wähle oben eine JSON- oder CSV-Datei oder lade passende Beispieldaten.
3. Datensätze prüfen: Suche links in der Liste und wähle einen Eintrag.
4. Details bearbeiten: Ändere Felder rechts im Editor.
5. Speichern: Lade die bearbeitete Datei über „Download“ wieder herunter.

Hinweis: Ungespeicherte Änderungen werden markiert.
