# Getting Started

1. Datei laden: Wähle oben eine JSON- oder CSV-Datei.
2. Datensätze prüfen: Suche links in der Liste und wähle einen Eintrag.
3. Details bearbeiten: Ändere Felder rechts im Editor.
4. Speichern: Lade die bearbeitete Datei über „Download“ wieder herunter.

Hinweis: Ungespeicherte Änderungen werden markiert.
